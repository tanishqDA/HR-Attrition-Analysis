# HR Attrition Analysis

HR Attrition Analysis using Python and Power BI.

## Project Overview

This project analyzes employee attrition patterns to identify the key factors influencing employee turnover. The analysis was performed using Python for data cleaning and exploratory data analysis (EDA) and Power BI for dashboard creation and business insights.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Dataset

The dataset contains employee information such as:
- Age
- Department
- Job Role
- Monthly Income
- Overtime
- Work-Life Balance
- Marital Status
- Attrition Status

## Project Workflow

1. Data Cleaning
2. Univariate Analysis
3. Bivariate Analysis
4. Business Insights Generation
5. Dashboard Development in Power BI

## Key Findings

- Employees working overtime show higher attrition.
- Sales department has the highest attrition rate.
- Sales Representatives have the highest attrition among job roles.
- Younger employees are more likely to leave the organization.
- Single employees exhibit higher attrition.
- Lower-income employees tend to leave more frequently.

## Recommendations

- Reduce excessive overtime.
- Improve employee engagement programs.
- Focus retention strategies on Sales teams.
- Review compensation policies.
- Enhance career growth opportunities for younger employees.
